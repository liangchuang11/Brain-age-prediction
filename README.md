These codes are designed to run on MATLAB R2021a and Python 3.8.8, and do not require any specialized hardware or install other software. After loading the input data, the above code can be directly clicked to run.

Brain_age_prediction_SHAP_demo.py was designed to predict the brain age and achieve the SHAP value for subjects.
PLS_Bootstrap.m was designed to perform Partial Least Squares (PLS) regression and bootstrapping to identify and rank the most significant gene features associated with MRI data.
PLS.m was designed to recalculates PLS regression to compute the explained variance, assess the statistical significance of the PLS components through permutation testing.
generate_gene_expression_matrix.py was designed to achieve gene expression matrix.
